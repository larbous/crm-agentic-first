# Código de conduta / Code of Conduct

## Nosso compromisso

Queremos que participar deste projeto seja uma experiência respeitosa e acolhedora para todas as pessoas, independentemente de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, nacionalidade, aparência, religião, orientação sexual ou de qualquer outra característica pessoal.

## O que esperamos

- Ser respeitoso e paciente, principalmente com quem está começando.
- Criticar o código e as ideias, nunca as pessoas.
- Aceitar feedback com boa-fé e dar feedback de forma construtiva.
- Assumir que a outra pessoa tem boa intenção até que se mostre o contrário.

## O que não é aceito

- Insultos, ataques pessoais, assédio, discriminação ou linguagem e imagens de cunho sexual ou violento.
- Divulgar dados pessoais de terceiros sem consentimento.
- Spam, autopromoção fora de contexto ou qualquer conduta que seria considerada inadequada num ambiente profissional.

## Aplicação

Quem mantém o projeto pode editar ou remover comentários, commits, issues e pull requests que violem este código, e restringir a participação de quem o descumprir. Para relatar um problema de conduta, escreva para **agencia.larbous@gmail.com** — a conversa é tratada com discrição.

Este código é inspirado no [Contributor Covenant](https://www.contributor-covenant.org).

## English summary

Be respectful, welcoming and constructive. Harassment, discrimination, personal attacks and doxxing are not tolerated. Maintainers may moderate or remove contributions and restrict participation. Report conduct issues to **agencia.larbous@gmail.com**. Inspired by the Contributor Covenant.
